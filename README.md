# Time Series Forecasting — Final Project

Group project for **CMU 95-835: Time Series Forecasting in Python, Fall 2026**.

We are developing a forecasting product MVP that connects a specific user need with real data, backtested forecasts, and a clear product workflow.

## Project Overview

The team is currently finalizing the use case, target users, dataset, and forecasting horizon.

Our work will cover:

- **Problem & Value Proposition**
- **Buyer Persona & Jobs to be Done**
- **Discovery Hypothesis & Differentiation**
- **Forecast Accuracy & Trust**
- **Wireframe**
- **Investment & Financials**

## Planned Repository Structure

- `notebooks/` — Data exploration, modeling, backtesting, and final forecasts.
- `data/` — Data required to reproduce the analysis, with source information.
- `wireframe/` — Interface mockups and user flows.
- `slides/` — Presentation materials.
